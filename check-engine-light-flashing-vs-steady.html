Check Engine Light: Flashing vs Steady and What to Do

By Dima · Published November 1, 2026 · Updated November 5, 2026 · 4 min read

Quick answer

A steady check engine light means the car has stored a fault. It usually isn't an emergency, but get the code read soon. A flashing light means an active misfire that can damage the catalytic converter: ease off, avoid hard acceleration and get the car checked as soon as you can. First thing to try: tighten the gas cap.

I try not to buy parts based on the warning light alone. I read the fault code first, and when it isn't obvious I look at live engine data as well. A code points you in the right direction, but it's the testing afterwards that shows which component has actually failed.

What does the check engine light mean?

The light, also called the malfunction indicator lamp, comes on when the engine computer detects a fault with the engine, fuel system or emissions equipment. It doesn't tell you what's wrong, only that a code has been stored.

Steady light vs flashing light

Steady

A fault has been detected. If the car drives normally, you can usually get to a workshop or read the code yourself within days. Don't ignore it for months.

Flashing

Often a misfire serious enough to send unburnt fuel into the exhaust, where it can overheat and damage the catalytic converter. Reduce speed and load, and have it checked as soon as possible.

Stop driving if the light comes on with heavy shaking, loss of power, overheating, an oil pressure warning or a strong smell of fuel or burning.

What to check first

  1. Gas cap. A loose or cracked cap is a common trigger. Tighten it until it clicks. The light may take several drives to clear.
  2. Recent work or fuel. A new fuel fill, a repair or a disconnected sensor can set a code.
  3. How the car feels. Rough idle, hesitation or reduced power point toward ignition or fuel problems.
  4. Other warning lights on the dash.

How to read the code

Cars built for modern emissions rules have an OBD-II port, usually under the dashboard near the steering column. A cheap plug-in reader, or a Bluetooth one paired with a phone app, will show a code like P0301. Many parts shops also read codes for free. The code points you to a system, not always a single failed part.

Common causes

  • Loose or faulty gas cap
  • Worn spark plugs or failing ignition coils
  • Oxygen (lambda) sensor faults
  • Dirty or faulty mass airflow sensor
  • Small vacuum or evaporative emissions leaks
  • A failing catalytic converter

Should you clear the code?

Clearing it turns the light off but doesn't fix anything, and the light usually returns. It also resets readiness monitors, which can cause a failed emissions or roadworthiness test until the car has been driven enough. Write the code down first.

FAQ

Can I drive with the check engine light on?

If it is steady and the car drives normally, usually yes for a short time, but get it checked soon. If it is flashing, avoid driving beyond what is necessary.

Why did my check engine light come on and then go off?

The fault may have been intermittent, such as a loose gas cap. The code is usually still stored, so a reader can still show it.

Will the light cause a failed inspection?

In many places, yes. An active light usually fails an emissions test.
